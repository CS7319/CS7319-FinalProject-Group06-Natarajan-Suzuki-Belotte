## Getting Started

1. install docker desktop
2. clone the repository
3. navigate to selected directory on your machine
4. run `docker-compose up --build`
5. open a browser
6. navigate to `localhost:4200`
7. enjoy the app
8. run `docker-compose down` to stop the app
9. run `docker-compose down --volumes` to remove all app data.
